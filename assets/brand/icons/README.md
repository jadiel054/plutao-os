# Icons (PNG)

Portal pack (12 PNGs) extracted from the brand portal.

Place files here and mirror PWA sizes:

```bash
# from brand portal download
cp icon_192.png ../../apps/web/public/icon_192.png
cp icon_512.png ../../apps/web/public/icon_512.png
cp icon_*.png .
```

Until PNGs are committed, the mark SVG in `../vectors/mark.svg` is the geometric source of truth (grade 24×24).
